**CSS Animation Showcase**

**Project Description**

CSS Animation Showcase is a simple and responsive webpage developed using HTML5 and CSS3. It demonstrates different CSS animations and transitions through interactive elements and smooth visual effects.

**Technologies Used**

- HTML5
- CSS3
- Visual Studio Code
- Live Server

**Animations Included**

1. Button Hover Effect: The button changes color and grows when the user moves the mouse over it.
2. Growing Box: The box smoothly increases in size on hover.
3. Loading Spinner: A circular spinner rotates continuously.
4. Bouncing Ball: An animated ball moves up and down automatically.

**Features**

- Four different CSS animations.
- Smooth transitions and hover effects.
- Automatic animations using CSS keyframes.
- Responsive design for mobile and desktop screens.
- Simple and user-friendly interface.
- CSS comments explaining the animations.

**How to Run the Project**

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open the "index.html" file.
4. Right-click and select Open with Live Server.
5. View and interact with the animations in your browser.

**Learning Outcomes**

- Learned how to create CSS animations and transitions.
- Practiced using the ":hover" selector.
- Learned to use "transform", "transition", and "@keyframes".
- Understood how to create rotating and bouncing animations.
- Practiced responsive web design using CSS media queries.
